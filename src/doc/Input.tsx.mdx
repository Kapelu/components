# Input

`Input` es un componente reutilizable para construir campos de formularios. Puede representar un `<input>` o un `<textarea>` mediante la propiedad `multiline`.

## Uso básico

```tsx
import Input from '@/components/ui/Input'

<Input label="Nombre" />
```

El componente también puede utilizarse directamente dentro de MDX:

<Input label="Nombre" placeholder="Escribí tu nombre" />

## Label flotante

<Input label="Nombre" floating placeholder=" " />

## Textarea

```tsx
<Input
  multiline
  label="Descripción"
  textareaRows={6}
/>
```

<Input multiline label="Descripción" textareaRows={4} />

## Contraseña

```tsx
<Input
  label="Contraseña"
  type="password"
/>
```

## Props principales

| Prop | Tipo | Descripción |
|---|---|---|
| `label` | `string` | Texto del campo |
| `floating` | `boolean` | Activa el label flotante |
| `multiline` | `boolean` | Renderiza un textarea |
| `textareaRows` | `number` | Cantidad inicial de filas |
| `icon` | `ReactNode` | Icono dentro del campo |
| `required` | `boolean` | Marca el campo como obligatorio |
| `className` | `string` | Clases del contenedor |
| `inputClassName` | `string` | Clases del campo |
| `labelClassName` | `string` | Clases del label |

## Ejemplo con formulario

```tsx
<form>
  <Input label="Nombre" name="nombre" required />
  <Input label="Email" name="email" type="email" required />
</form>
```
