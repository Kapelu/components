# Button

`Button` es un componente reutilizable que centraliza la apariencia, el comportamiento y la interacción de botones y enlaces dentro de la aplicación.

## Uso básico

```tsx
import Button from '@/components/ui/Button'

<Button variant="primary">
  Guardar
</Button>
```

También puede utilizarse directamente dentro de esta documentación porque el catálogo MDX registra `Button` como componente disponible:

<Button variant="primary">Primary</Button>

<Button variant="secondary">Secondary</Button>

<Button variant="ghost">Ghost</Button>

## Variantes

`Button` dispone de cuatro variantes:

```ts
type ButtonVariant = 'primary' | 'secondary' | 'ghost' | 'menu'
```

| Variante | Uso principal | 
|---|---|
| `primary` | Acción principal |
| `secondary` | Acción secundaria |
| `ghost` | Acción discreta |
| `menu` | Navegación y elementos de menú |

## Tamaños

<Button variant="primary">Guardar</Button>

<Button variant="secondary">Cancelar</Button>

<Button variant="ghost">Editar</Button>

<Button variant="menu">Empleados</Button>


```ts
type ButtonSize = 'sm' | 'md' | 'lg'
```

<Button size="sm">Small</Button>

<Button size="md">Medium</Button>

<Button size="lg">Large</Button>

## Estado de carga

Cuando `loading` es `true`, el botón queda deshabilitado y muestra `Cargando...`.

<Button loading>Guardar</Button>

## Navegación

Cuando se proporciona `href`, `Button` utiliza `next/link` internamente.

```tsx
<Button href="/empleados">
  Empleados
</Button>
```

<Button href="/componentes" variant="primary">Abrir componentes</Button>

## Contenido React

`children` acepta `React.ReactNode`, por lo que puede contener otros elementos React.

```tsx
<Button>
  <span>+</span>
  Nuevo componente
</Button>
```
